Быстрый старт

1. ЗАВИСИМОСТИ — поставь недостающее (pip install -r requirements.txt, playwright install chromium)
2. НАСТРОЙКИ — впиши ключи (2captcha, IMAP, TG api_id/hash)
3. ПОЧТА — загрузи пул data/working_mails.txt или используй voidash
4. ПРОКСИ — нажми ЗАБРАТЬ (бесплатно) или вставь свои платные
5. ПРОВАЙДЕРЫ — выбери таргет, жми RUN. Аккаунты падают в БАНК, экспорт CSV/JSONL
👻 иишко · universal-autoreg v2 · stdlib-only сервер, данные в data/, секреты в config.json (gitignored)

клик по строке — детали и питфолы · RUN N — волна на N аккаунтов

ПОЧТА

три канала доставки OTP: t-online пул, voidash temp-inbox, gmail +alias

T-ONLINE IMAP-ПУЛ

Файл: data/working_mails.txt, формат email:password по строке (canonical, без dash-алиасов). Индекс: data/email_state.json. IMAP-пароль — в НАСТРОЙКАХ.

VOIDASH TEMP-INBOX

Без регистрации, supply безлимит. Часть таргетов блокирует eu.cc-домены — смотри notes провайдера.

GMAIL APP-PASSWORD

user + 16-символьный app-password в НАСТРОЙКАХ. Плюс-алиасы канонизируются не всеми таргетами.

БАНК АККАУНТОВ

data/bank.jsonl · секреты маскируются · клик по значению — копировать
